## 1. Реализация стека (Stack)

Класс `Stack` реализует структуру данных "стек" по принципу LIFO (Last In, First Out).

### Методы:
- `is_empty()` - проверка на пустоту
- `push(item)` - добавление элемента на вершину
- `pop()` - удаление и возврат верхнего элемента  
- `peek()` - просмотр верхнего элемента без удаления
- `size()` - количество элементов в стеке

### Пример использования:
```python
stack = Stack()
stack.push(1)
stack.push(2)
print(stack.peek())  # 2
print(stack.pop())   # 2
print(stack.size())  # 1
```

## 2. Проверка сбалансированности скобок

Функция `is_balanced_brackets()` проверяет правильность расстановки скобок `()`, `[]`, `{}`.

### Примеры:
```python
print(is_balanced_brackets("((()))"))     # Сбалансированно
print(is_balanced_brackets("{[()]}"))     # Сбалансированно  
print(is_balanced_brackets("({)}"))       # Несбалансированно
```

## 3. Рефакторинг почтового модуля

Класс `EmailClient` для работы с Gmail через SMTP и IMAP.

### Основные улучшения:
- Объектно-ориентированная структура
- Обработка ошибок
- Следование стандарту PEP8
- Убраны захардкоженные значения

### Пример использования:
```python
# Создание клиента
client = EmailClient('your_email@gmail.com', 'your_app_password')

# Отправка письма
success = client.send_email(
    recipients=['recipient@email.com'], 
    subject='Тема письма', 
    message='Текст сообщения'
)

# Получение писем
email_message = client.receive_email('Subject Filter')
```
